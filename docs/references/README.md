# Références

Dossier destiné aux **références ajoutées au fil de l'eau** : chartes graphiques,
exemples d'animations, liens de doc Remotion, briefs clients, palettes, polices,
specs de formats, etc.

## Comment ajouter une référence

1. Déposer le fichier ici (`.md`, image, PDF, lien…) avec un nom clair.
2. Ajouter une ligne dans l'index ci-dessous pour qu'une IA la retrouve.

> Au démarrage d'un nouveau projet, l'IA doit parcourir ce dossier en plus de
> [CLAUDE.md](../../CLAUDE.md) et [remotion-rules.md](../remotion-rules.md).
